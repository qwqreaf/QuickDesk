QuickDesk 4.2.0.1 upgrades the bundled MCP bridge from rmcp 0.17 to rmcp 3.7.0.

- Supports legacy MCP initialization and MCP 2026-07-28 stateless discovery over Streamable HTTP.
- Migrates resources, prompts, and server configuration to the rmcp 3.x APIs.
- Adds explicit allowed HTTP Host configuration and OpenAI connection examples.
- Adds protocol compatibility tests for HTTP, stdio, tools, resources, and prompts.

Download the arm64 DMG for Apple Silicon Macs. It contains QuickDesk.app with its MCP bridge, remoting helpers, and built-in skills. SHA256SUMS contains the download checksum. This release does not include an Intel build.

The app is ad-hoc signed, as in the upstream packaging process, and is not Apple notarized. A live OpenAI end-to-end connection has not been tested; remote access requires a reachable MCP endpoint with appropriate HTTP authentication. See docs/mcp-integration.md for setup.
